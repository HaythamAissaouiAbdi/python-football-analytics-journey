# Python Zero to Hero

Daily Python course for building real skill through consistency, review, and projects.

## How This Works

Every day you come back and ask for the next lesson. Each lesson should include:

1. Review from previous days
2. New theory
3. Guided examples
4. Practice drills
5. A small challenge
6. A short reflection in `progress_log.md`

We will stack concepts over time so nothing gets learned once and forgotten.

## Daily Routine

- 10 minutes: review
- 20 minutes: new concept
- 25 minutes: practice exercises
- 20 minutes: mini challenge
- 5 minutes: commit notes

Total target: 60-90 minutes per day.

## Folder Map

- `course_plan.md`: full learning roadmap
- `progress_log.md`: daily notes, scores, and reflections
- `lessons/`: lesson notes created day by day
- `exercises/`: practice files
- `projects/`: larger builds
- `solutions/`: your completed work

## First Goal

By the end of this month, you should be comfortable enough with Python to build small programs alone, read documentation without panicking, and start a serious summer project.
