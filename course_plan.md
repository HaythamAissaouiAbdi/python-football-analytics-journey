# Python Zero to Hero Course Plan

This plan is built for consistency: one lesson per day, with spaced review and cumulative practice.

## Phase 1: Reboot Python Basics

Day 1: Setup, running Python, variables, printing, input  
Day 2: Numbers, strings, type conversion, f-strings  
Day 3: Conditionals, comparisons, boolean logic  
Day 4: Loops with `for` and `while`  
Day 5: Lists and indexing  
Day 6: List methods, loops over lists, simple stats  
Day 7: Review challenge 1: training tracker

## Phase 2: Think Like a Programmer

Day 8: Functions and parameters  
Day 9: Return values and clean program structure  
Day 10: Dictionaries  
Day 11: Nested data: lists of dictionaries  
Day 12: Error handling and debugging habits  
Day 13: Files: reading and writing text  
Day 14: Review challenge 2: football match log analyzer

## Phase 3: Useful Python

Day 15: Modules and imports  
Day 16: Dates, times, and training logs  
Day 17: CSV files  
Day 18: Basic data analysis without libraries  
Day 19: Intro to `matplotlib` or simple charts if available  
Day 20: Project planning and decomposition  
Day 21: Review challenge 3: weekly performance report

## Phase 4: Solid Foundations

Day 22: Classes and objects  
Day 23: Methods, attributes, and object design  
Day 24: Testing with simple assertions  
Day 25: Code style, naming, and refactoring  
Day 26: APIs and JSON basics  
Day 27: Git and GitHub workflow  
Day 28: Capstone project build day

## Phase 5: First Capstone

Days 29-35: Build a football training analytics app.

Possible features:

- Add daily training sessions
- Track minutes, intensity, sleep, soreness, and mood
- Calculate weekly load
- Flag risky jumps in workload
- Export reports
- Create simple charts

## Review System

Every lesson includes:

- 3 questions from yesterday
- 1 task from 3-5 days ago
- 1 small cumulative challenge

## Rules

- Small daily progress beats heroic random sessions.
- You must type code yourself, even if I show examples.
- Every day ends with a commit once your work runs.
- Mistakes are data. We debug them calmly.
