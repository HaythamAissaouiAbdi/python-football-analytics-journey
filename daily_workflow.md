# Daily Python Lesson Workflow

When starting a lesson, say:

```text
Let's do Python Day N.
```

The lesson should follow this rhythm:

1. Review yesterday with 3 quick questions.
2. Revisit one older concept.
3. Learn one new concept.
4. Complete guided examples.
5. Solve exercises in `solutions/day_N.py`.
6. Run the file and debug mistakes.
7. Update `progress_log.md`.
8. Commit the day with a clear message.
9. Push to GitHub if the remote is connected.

## Daily Commit Message Format

```text
Complete Python day N
```
